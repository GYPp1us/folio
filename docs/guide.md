# Folio 使用指南

## 使用

- 新会话沿用当前沙箱。左侧顶部默认收起的菜单提供当前沙箱管理、二级切换菜单和新建入口。
- 输入框旁提供实时模型目录、主模型思考强度、工具审核和翻译审核。打开模型选择器会刷新空闲 SDK 会话的目录；执行中使用当前连接已返回的目录。
- 工具审核默认 `auto`，由 Claude Code 的分类器审核工具调用；不支持此模式的模型回到逐次授权。也支持 SDK 的编辑、规划、拒绝询问与显式完全放行模式。
- 翻译审核默认「静默通过」：规则未发现敏感项时自动翻译并发送；发现敏感项时才展开右栏。选择「手动标记」则保留隐私检查与英文确认两步，可选中原文补充标记。面板出现时自动滚到会话底部。
- 执行时输入框继续接受补充要求，经过同样的检查与翻译后以 `priority: next` 排队，不主动打断当前生成或工具。跟踪 SDK 的消息 UUID 回执，在补充要求尚未消费时继续保持运行；仅显式“中断”调用 interrupt。
- `/usage`、`/context`、`/mcp`、`/skills`、`/tasks` 等命令连接对应控制面板；其他命令根据实际 `supportedCommands()` 目录提供。`/clear` 在当前沙箱建立新会话。
- 「用量与控制」提供用量、上下文、技能、MCP、任务、检查点回滚和 SDK 控制。安装的 SDK 0.3.309 共 30 个公开 Query 控制方法均有入口或对应流程；`streamInput` 统一走已审阅输入框。上游不支持或请求失败时直接显示错误。
- 套餐额度依赖登录方式和 SDK 返回值。setup-token 连接可能只有会话费用和 token 用量，没有套餐额度；缺失值显示不可用。用量接口是上游实验 API。
- 查询套餐用量：左侧沙箱管理 →「网页登录，启用套餐用量」。容器内的原生 `claude auth login` 发起 OAuth；在浏览器授权，必要时把一次性授权码粘贴回工作台。完整凭证保存在该仓库的状态卷中，CLI 自行刷新，容器重建后保留。每个沙箱单独登录，避免复制刷新令牌产生竞争。
- 网页登录成功后，此沙箱不再注入 `CLAUDE_CODE_OAUTH_TOKEN`，SDK 的 `/usage` 使用完整登录权限。其他沙箱仍沿用原登录方式。可在管理中切回长期 token；这不会删除卷内网页登录凭证。取消登录会清理本次原生登录进程，保留其他任务和容器。
- 中文、双语、原文三种显示可切换。MCP 的动态增删和启停作用于当前 SDK 连接；持久配置可通过 SDK 设置写入对应配置源。

## 发布与 Shell（0.5）

设备登录互不抢占，Cookie 有效期 30 天，活跃设备逐日续期。服务端只持久保存 Cookie 摘要和加密验证数据，升级/重启不再清空登录；退出只影响当前设备，访问密码变化会撤销旧设备登录。旧版内存登录无法迁移，升级到此版本后需重新登录一次。

断网或服务重启后自动重连并恢复当前会话，不自动重发任务。检测到新构建后自动刷新页面；存在未发送输入、附件、审阅或运行任务时延后刷新，保留草稿，当前输入处理完成后再更新。Reports 同时刷新展示授权。只有会话标识保存在浏览器偏好里，不把输入草稿写入浏览器持久存储。

- 主页面的 Reports 入口打开 `/report`。所有发布项位于 `/report/<id>/`，沿用 Folio 登录，不需要额外 DNS。未登录打开报告会先显示工作台登录页。
- `publish_service` 工具接受 `/work/` 下的静态文件/构建目录，或服务启动命令、工作目录和端口。工具说明引导 Claude 主动用于报告、Demo 和 Web 应用，只暴露运行约束和返回链接；不说明翻译流程或前端实现。原 `publish_file` 的 HTML 也会生成独立报告链接。
- 静态快照独立于原会话保存，以 AES-256-GCM 加密；最多 1,000 个文件、25 MB，拒绝符号链接和路径越界。报告默认保留到手动删除，独立于会话的自动保留周期。可删除发布而保留工作区源文件。
- 动态发布运行在独立的非 root 容器，工作区只读，`/tmp` 可写，不挂载 Claude 状态和登录凭证。CPU、内存、进程数受限，同时最多六个服务，默认运行两小时，最长一天。发布网关只监听 `127.0.0.1:8124`，共享本机沙箱鉴权。停止/到期会清理运行容器，工作区卷保留；沙箱紧急断网同步到其发布服务。
- HTTP、SSE 和 WebSocket 经已登记发布项代理，不能指定任意目的地址。Folio Cookie/Authorization 不转发给应用。展示页签发单项、限时能力，生成内容使用无 `allow-same-origin` 的 iframe 和响应 CSP；禁止主站访问、远程资源、worker 和浏览器存储。应用需使用相对资源/API 地址，模块依赖先打包。根路径资源做前缀转换，复杂应用仍需适配基础路径。
- HTML 首屏可见文本在后台并行翻译，带最近五轮对话，原文/中文切换通过页面消息应用。动态脚本自行生成的新文案不保证自动翻译。Agent 询问正文和选项也下传翻译，提交保留 SDK 原始问题键和选项值。
- 左下角“用量与设置”默认收起，悬停展开沙箱累计 token、账号额度与连接设置，触屏可点击。右上角“用量与控制”保留所有 SDK 控制入口；`</>` 打开当前沙箱真实 PTY Shell，支持缩放、Ctrl+C，关闭窗口会结束该 Shell。
- `scripts/verify-publishing.ts` 在独立验收仓库测试真实目录快照、容器服务、网络切断/恢复、PTY 和 EOF 清理，最后停止测试容器，保留工作区卷。

## 翻译与隐私

翻译器明确中继 **用户 ↔ Claude Code** 的发言，仅翻译当前消息，参考最近五轮完整往返。每次请求显式关闭思考，按接口选择 `reasoning_effort: off/none`、`thinking: disabled` 或 Qwen 参数，不静默回退到开启思考。Command Code 网关自动选择 `off`。代码块和行内代码冻结保留，不翻译可执行内容。

1. 本地规则识别姓名标签、邮箱、电话、身份证、银行卡、内网 IP、凭证、JWT、私钥与带凭证 URL；也可手动标记。
2. 每个敏感项选择占位、原样透传、非密钥 ENV 或重写。所有已标记的原始值在翻译前都会被替换，透传值只在翻译后还原。
3. 翻译必须保留所有占位符及出现次数；缺失、新增或英文译文残留中文都会阻止发送。
4. 回复先遮罩已知敏感值再翻译，中文显示时还原占位符；原文保留实际 CC 输出。翻译失败保留原文并明确报错。

规则会漏项，代码库与工具输出也可能进入模型上下文。此功能是审阅辅助，不能保证识别所有个人信息。ENV 可被容器工具和 Claude 读取，不是隐私隔离；密钥不允许封装 ENV。占位模式下生成的文件可能仍包含占位符，工作台不会自动把秘密写回文件。

SDK 询问中的中文回答也会翻译。此类回答识别到敏感信息时阻止提交，提示改用输入框完成隐私处理。

## 沙箱与状态

`server/sandbox.ts` 基于用户提供的 cc-sandbox 示例，实现 `spawnClaudeCodeProcess`，将 SDK 的 `command / args / cwd / env / signal` 原样交给 HTTP duplex 适配器；SDK 参数不经 shell、不修改。stdout/stderr/退出码按 Docker 帧拆分。宿主机环境密钥不继承到容器。

同一仓库同一时刻运行一个 SDK 会话。SQLite 维护 `WebUI session ↔ SDK session_id ↔ repo ↔ state/work volumes`。容器重建后使用 SDK `resume` 恢复；状态卷 `cc-state-<repo>`、工作卷 `cc-work-<repo>` 独立持久。空闲 SDK 连接三分钟后关闭，容器由用户管理。当前应用按单进程、单人工作台部署。

工作台消息和隐私映射加密保存。备份需要 SQLite、`settings.enc` 与 `vault.key`；丢失密钥无法解密。保留期默认 30 天，不自动删除沙箱卷。**卷中可能包含明文会话**；完全销毁需要输入确认文字并勾选确认，后端再次校验，绝不强制删除使用中的卷。

**启用网页登录后，状态卷包含完整 OAuth 凭证（包括刷新令牌）**。现有沙箱备份接口排除 `.credentials.json` 和 `.oauth_token`，因此从备份恢复后需重新网页登录；它不保证排除卷内其他形式的秘密。默认备份目录限制为仅 root 可访问。一次性授权码只送入对应登录进程的 stdin，不进入消息、翻译、持久设置或日志。完整登录只授予访问权限；上游限流时仍可能暂时无法读取套餐用量。

## 部署与验收

部署详见 [deploy/README.md](../deploy/README.md)。升级先用 `deploy/stage-la.sh` 暂存，再用 `deploy/activate-la.sh` 备份加密配置和一致 SQLite、切换链接、重启并检查健康，失败回滚。已有数据独立于版本目录。

`scripts/verify-workbench.ts` 使用独立数据库和验收仓库验证真实 SDK、模型目录、用量、自动审核、翻译关闭思考与执行中插话，最后关闭 SDK 和测试容器，保留测试卷。不会读取用户会话或工作区。

服务默认只监听 loopback，使用同源检查、HttpOnly/SameSite cookie、登录限流、CSP 和隔离的 HTML 预览。公开部署需 HTTPS；SSE 代理关闭 buffering。服务器配置与 token 仅服务账户可读，不授予工作台 Docker socket 或 sudo。

## 开源基础

实际复用 React、Radix UI、Fastify、官方 Claude Agent SDK、Lucide、React Markdown/remark-gfm、Zod 和 Node SQLite，版本由锁文件固定。

- [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness)：参考会话、执行和持久状态的分离。
- [CloudCLI](https://github.com/siteboon/claudecodeui)：参考项目导航和权限交互，没有复制 AGPL 源码。
- [Anthropic skills](https://github.com/anthropics/skills)：参考衬线、暖纸色和低饱和橙色的排版。
- 用户提供的 cc-sandbox 适配器：实际传输基础，增加中断、帧校验和生命周期处理。

本项目是独立工作台，不是 Anthropic 官方产品。

## 附件、产物与翻译策略（0.4）

- 上行支持静默翻译、逐步确认、直接发送。直接发送保留原语言，文字仍经过本地敏感模式检查。
- 下行默认仅翻译对话回复（包含 Claude 中间发言），工具调用、调用说明和思考可按需翻译；也支持翻译全部、手动翻译。每个未翻译内容块可单独翻译；Claude 发言按对话默认展开，工具详情默认折叠并持久保存。
- 左下角显示五小时／周额度的已使用百分比与重置时间，时间按浏览器本地时区显示。后台每分钟缓存，遇到上游错误退避，缺失数据用破折号显示。
- 支持选择、拖入、粘贴文件或图片，每条最多 12 个、单个最多 25 MB。输入 `@` 或点击附件的 @ 按钮引用。批准后的副本通过 Python 文件桥写入 `/work/.folio/inputs/`，SDK 消息携带真实路径；标准小图片同时使用原生 image content。
- **用户上传图片不做敏感检查、OCR 或翻译**，按原图交给 Claude Code。文字附件逐项选择透传或占位符；无法检查的格式需要明确选择原样发送。
- Claude Code 可用内置 MCP 工具 `mcp__folio__publish_file` 发布 `/work/` 中的产物。HTML 需使用 `folio-i18n` 扁平字典及 `data-i18n` 属性；翻译独立并行，携带最近五轮完整对话及当前请求。切换页面语言不重载 iframe。
- HTML 在无同源权限的 sandbox iframe 中展示，CSP 禁止网络、表单和嵌套页面；本地脚本、样式、图片打包内联。支持预览、查看源文件及下载原件。发布工具只读取普通工作区文件，逐层拒绝符号链接。
- Claude 生成的输出图片可进入视觉翻译，先在服务器通过 Tesseract 做本地文字遮盖，再请求视觉模型。中文说明用于悬停提示和点击预览；原上传图片按字节哈希匹配时继续免翻译。视觉模型可在连接设置中单独指定。
- WebUI 附件、产物和翻译记录使用 AES-256-GCM 加密，备份需包含 `assets/`、SQLite、`settings.enc` 与 `vault.key`。沙箱工作卷和状态卷依然可能保存明文，删除 WebUI 会话不等于清除沙箱卷。

交互参考 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) 的附件栏、产物预览和折叠工具详情模式；按本项目的 SDK 与沙箱协议实现。额外使用 parse5 解析页面、Sharp 处理输出图片，均由锁文件固定版本。`scripts/verify-media.ts` 在独立验收沙箱验证文件桥、原生图片输入和 MCP HTML 发布。

## 用量与行内展示（0.4.1）

- usage 页汇总 Claude Code 会话的非缓存输入、输出、缓存读取、缓存写入及总 token，提供逐模型表格。使用含子代理的 SDK 累计 `model_usage` 快照，不叠加连续结果或单轮 `usage`；重连、异常空快照会保留已有累计值。缺失计数显示 —。参考 [SDK 用量口径](https://code.claude.com/docs/en/agent-sdk/cost-tracking)。
- Markdown 图片支持工作区路径、私有资产、data URI 和普通 HTTP(S) 图片。SVG 与 HTML 代码块、直接返回的 HTML 片段可行内预览，支持源码、放大、单独翻译。HTML 自动提取静态文本为本地化字典，预览高度随内容调整，脚本保持在隔离 iframe 内；普通源码仍可复制。
- 接入 mdast-util-from-markdown 与 parse5 分析回复，翻译正文时冻结 HTML/SVG 结构，避免翻译修改脚本或属性。HTML 依赖沿用本地资源规范。SVG 图像使用图片上下文展示，提供给视觉翻译的栅格副本会去除脚本和外部文件引用。
- 升级时将旧版“全部翻译”默认值一次性迁移为“仅翻译回复”，保留手动模式；之后的用户选择继续保存。新会话默认仅翻译回复。

## 执行状态与对话层级（0.4.2）

- 输入框上方显示后端真实阶段与该阶段耗时：输入检查、翻译、准备沙箱、传递、等待模型、实际思考、工具执行、确认、重试、上下文压缩和输出翻译。耗时持续更新，不把长时间沉默推断为思考。会话 SSE 在重连时恢复活动阶段和原起点；断线显示重连状态。
- Claude 中间发言与最终回复同属对话，默认展开。工具调用、调用说明、思考处于下一层并默认折叠；工具结果归入对应调用，各块保留独立翻译入口。
- 新 SDK 连接的附加提示与发布工具只说明英文输出、隐私占位符和普通文件/页面发布，不说明翻译流程。普通 HTML 的静态文本目录由 Folio 内部生成，工作区源文件不变；已有会话的历史上下文保留。
- 无请求体的请求不再设置 JSON Content-Type；服务端兼容旧客户端的空 DELETE，同时保留执行中会话保护与带请求体操作的 JSON 校验。

## 长对话与滚动（0.4.3）

- 使用 React Virtuoso 窗口化历史：只挂载视口附近的消息/助手发言/工具行，长回复在 Markdown 块边界继续分段。工具结果按轮次与调用 ID 关联，代码、HTML 及参考链接保持可用。
- 默认跟随最新输出及图片/页面的高度变化；用户上翻、拖动或使用键盘阅读历史时暂停跟随，可点击“回到最新”恢复。发送新任务、插话或弹出隐私审阅会恢复到底部。
- 当前轮结束后关闭该轮打开的工具详情，将最后一段最终回复开头对齐阅读区顶部。用户正在阅读历史时不抢占视角；翻译到达或切换中英文时继续保留阅读起点。短回复也能定位到开头。
- 新版 SSE 只传文本增量，重连快照带完整当前流，兼容旧版客户端的累计文本模式。运行后补取最多八条消息，避免发送/完成时重复下载整段历史；输入编辑与状态计时不重新解析历史 Markdown。

手机端使用抽屉导航、横向模型/翻译选项和上下排列的双语回复；隐私标记面板移到对话下方。键盘或窗口高度变化时，列表仍按当前跟随/阅读状态调整。Android 安装包与校验和见项目 Releases。

左下角 token 统计汇总当前沙箱在 Folio 中保留的所有会话；相同 SDK 会话取累计计数的高水位去重，并标出尚未同步的用量。右上角 `/usage` 和输入命令 `/usage` 只统计当前会话。5 小时与每周百分比单独标为账号共享额度，不作为沙箱 token 使用率。沙箱汇总只读取已保存快照，不逐个启动历史 SDK 会话。
