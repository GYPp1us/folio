# Folio

Folio 的 Android 安装包发布仓库，连接 [Folio 工作台](https://folio.arcol.site)。

## 下载

在 [Releases](https://github.com/GYPp1us/folio/releases) 下载 APK；Android 10 及以上版本，建议更新系统 Android System WebView。`SHA256SUMS.txt` 可校验安装包。

首次打开请输入已有的 **Folio 访问密码**。Claude 登录、模型配置与沙箱仍由 Folio 服务器管理，APK 不包含这些凭据。

支持文件与图片选择、已登录文件下载、返回导航。网页功能随线上服务更新。

此仓库现阶段仅用于分发安装包；应用源码尚未公开。
